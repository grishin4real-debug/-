# Человек-паук и Веном (Three.js)

Браузерная игра с процедурными 3D-моделями Человека-паука и Венома: паутина и раскачивание, щупальца симбиота, лазание по стенам, анимации.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # статическая сборка в dist/
```

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / Shift | движение / бег |
| Пробел | прыжок, прыжок от стены |
| ЛКМ или E (держать) | паутина (у Венома — щупальце), раскачивание; отпустить — бросок с сальто |
| Q | атака: комбо паука / удар щупальцами Венома |
| F (или ПКМ) | выстрел паутиной / захват щупальцем |
| T, 1, 2 | превращение / выбор героя |
| Мышь (клик для захвата), стрелки, колесо | камера, зум |
| H | скрыть подсказки |

## Структура

- `src/rig.js` — скелет гуманоида, проекция глаз на голову, процедурные позы (бег, прыжок, раскачивание, лазание, «супергеройское» приземление, атаки).
- `src/spiderman.js`, `src/venom.js` — модели: текстуры костюма с паутиной и эмблемой, глаза, пасть с клыками и языком, когти.
- `src/tentacles.js` — щупальца симбиота.
- `src/world.js` — процедурный город и коллизии.
- `src/main.js` — физика, ввод, камера, манекены, эффекты.
